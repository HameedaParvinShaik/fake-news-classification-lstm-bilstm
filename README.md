# Fake News Classification Using LSTM and BiLSTM

## Overview
This academic deep learning project compares Long Short-Term Memory (LSTM) and Bidirectional LSTM (BiLSTM) models for binary fake news classification.

## Objectives
- Classify news articles as fake or real.
- Compare LSTM and BiLSTM model performance.
- Explore how bidirectional sequence processing captures text context.

## Methodology
1. Dataset loading and preprocessing
2. Text tokenization and sequence padding
3. Stratified train-test split
4. LSTM and BiLSTM model training
5. Three-fold cross-validation and performance evaluation

## Recorded Results

| Model | Test Accuracy |
|---|---:|
| LSTM | 92.98% |
| BiLSTM | 99.62% |

*These are the results recorded in the project notebook.*
